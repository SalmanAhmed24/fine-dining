# Verdigris — fine dining site

Next.js 16 (App Router) · GSAP + ScrollTrigger · Framer Motion · Lenis smooth scroll · TypeScript.

## Run it

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start   # production (use this for Lighthouse)
```

Requires Node 20.9+.

## Make it yours

- **Copy, hours, address, menu, prices:** `lib/content.ts`
- **Photos:** `/public/images` holds crops of your five supplied photos, upscaled 4× with Real-ESRGAN (x4plus). The hero has a separate portrait crop (`hero-mobile.jpg`) served to tall screens through `<picture>`, so phones get a properly sized image instead of a stretched slice of the wide one. To swap in new photography, keep the file names and aspect ratios:
  - `hero.jpg` — wide landscape, 3840 px wide; `hero-mobile.jpg` — 9:16 portrait, 1100 px+ wide
  - `table-wide.jpg` — 21:10, 2000 px+ wide
  - `detail-*.jpg`, `course-*.jpg` — 4:5 portrait, 1000 px+ tall
  - `counter.jpg`, `pass.jpg` — 9:10, 1200 px+ tall
  - `gallery-*.jpg` — square, 1000 px+
  next/image serves AVIF/WebP at quality 85. If you replace a file while `next start` is running, delete `.next/cache/images` so the old optimized version isn't served.
- **Domain:** set `site.url` in `lib/content.ts` (used for canonical URL, sitemap, Open Graph and JSON-LD).
- **Bookings:** the form in `components/Reserve.tsx` simulates sending. Swap the `setTimeout` in `onSubmit` for your booking provider or a server action.
- **Colours and type scale:** CSS variables at the top of `app/globals.css`.

## Where the motion lives

| Section | File | Library |
|---|---|---|
| Hero letter reveal + parallax | `components/Hero.tsx` | GSAP |
| Giant word across three images | `components/Triptych.tsx` | GSAP ScrollTrigger (scrub) |
| Statement lights up word by word | `components/Statement.tsx` | GSAP ScrollTrigger (scrub) |
| Image grid parallax + frame opening | `components/Room.tsx` | GSAP ScrollTrigger |
| Pinned horizontal courses (desktop) | `components/Courses.tsx` | GSAP pin + containerAnimation |
| Nav hide/show, mobile menu | `components/Nav.tsx` | Framer Motion |
| Seating/tab indicators, rolling numbers, photo wipes, success state | `components/Reserve.tsx` | Framer Motion (layoutId, AnimatePresence) |
| Magnetic buttons | `components/Magnetic.tsx` | Framer Motion springs |
| Cursor ring (desktop only) | `components/Cursor.tsx` | Framer Motion |
| Smooth scrolling | `components/SmoothScroll.tsx` | Lenis synced to GSAP's ticker |

Everything respects `prefers-reduced-motion`: GSAP effects run inside `gsap.matchMedia`, Lenis and the cursor switch off, and the courses become a native swipe row.

## Performance / accessibility notes

- Fonts (Bodoni Moda, Hanken Grotesk — SIL OFL) are self-hosted via `next/font/local`.
- Framer Motion features load lazily (`LazyMotion`), the cursor is a client-only dynamic import, CSS is inlined.
- Skip link, focus-visible styles, focus trap in the mobile menu, keyboard-operable tabs (arrow keys), labelled form fields, 44px+ touch targets, AA contrast.
- `robots.txt`, `sitemap.xml`, web manifest, Open Graph/Twitter cards and Restaurant JSON-LD are generated by the App Router.
